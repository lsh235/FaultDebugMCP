# v1.3.0-alpha.29: typed static call relations

Date: 2026-10-17 (Asia/Seoul). Python package `1.3.0a29`; native project
version remains `1.3.0`. Implementation: `37b0931bc07b2265f0210c37bcbd3c5c2bb0d09b`.

This alpha publishes `get_call_relations` output schemas in the full and
focused MCP profiles. It types the stable function/direction/evidence/bundle
envelope and documents common relation fields, while allowing producer-defined
relation fields and values from hash-verified version-1 indexes. Direct and
unresolved outbound rows, inbound caller rows and empty results retain their
existing text values. Static index relations remain hypotheses, not evidence
that a runtime call occurred. Index generation, bundle verification, inputs,
errors, tool inventory and evidence are unchanged.

Both profiles keep 27/84 and 15/44 tools/parameters; published output schemas
increase to 13 full and 12 focused.
