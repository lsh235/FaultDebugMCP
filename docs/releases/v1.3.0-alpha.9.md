## Behavior

`faultdebug integrate --execute-build` first runs the existing isolated-plan
validation, then executes only the `configure`, `build`, `index` and `bundle`
command arrays. It writes combined output to
`.faultdebug-adopt/build.log`, stops on the first failed stage, validates the
produced source bundle and reports its path. The normal `integrate` command
remains plan-only. The application `run` stage is never executed by this flag;
launch remains explicit and separate.

Executing CMake configure/build runs the selected project's CMake files and
build rules as the current user. This is an explicit convenience path, not a
sandbox. Existing restrictions on a fresh non-overlapping build directory,
reserved CMake options and project hooks still apply. See the
[research and decision](../integration-execute-build-research.md) and
[adoption guide](../existing-project-adoption.md).
