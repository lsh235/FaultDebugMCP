# v1.3.0-alpha.26: actionable focused-profile guidance

Date: 2026-10-17 (Asia/Seoul). Python package `1.3.0a26`; native project
version remains `1.3.0`. Implementation: `cd45e67d269cf8b487072b4204542e8904082ecb`.

Alpha26 tailors eight `tools/list` descriptions in the focused MCP profile so
each named alternative is actually exposed there. The eight affected tools
cover store health, capture triage, RPC and incident inspection, artifact
discovery and static relations. The 27-tool full profile keeps its original
cross-tool guidance. Tool membership, parameter schemas, annotations, output
schemas and runtime behavior are unchanged.

The change responds to a concrete selection-guidance defect in a profile used
for Glama: eight descriptions referenced one or more tools hidden from that
15-tool catalog. The [TDQS rubric](https://github.com/glama-ai/tool-definition-quality-score)
scores definitions in sibling context and evaluates whether descriptions
distinguish when to use alternatives. This is a rubric-backed quality
correction, not an observed score increase.
