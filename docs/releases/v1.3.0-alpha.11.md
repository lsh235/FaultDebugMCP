## Behavior

`faultdebug integrate --fault-report` is an explicit opt-in that requires
`--execute-target` (and therefore `--execute-build`). After target launch has
returned exactly one checksum-validated `.fault` artifact, it writes the
existing JSON, Markdown and HTML report into a sibling `<artifact-stem>-report`
directory. The report writer verifies the artifact and supplied source bundle.
Existing and symlinked output destinations are refused.

Target status and report status remain separate. A nonzero target can still
produce a report when its capture validates, but its target and overall
integration statuses remain failed. A capture with no crash record produces a
report that says no crash was recorded; it does not infer a fault or root cause.
Without `--fault-report`, alpha10 behavior remains unchanged.

See the [research](../integration-fault-report-research.md),
[feature review](../integration-fault-report-review.md), and
[adoption guide](../existing-project-adoption.md).
