# v1.3.0-alpha.34

Development release for typed service-flow MCP output. This is a reviewable
alpha milestone; stable release acceptance remains **NO-GO**.

## Scope

`get_service_flow` now publishes a discriminated structured result for its
summary and seven paged collections. Stable envelope, pagination, snapshot,
count, and limitation fields are typed. Collection rows, count extensions, and
future root fields remain open so producer-owned evidence is preserved. The
tool stays in the full profile; the focused 16-tool workflow is unchanged.

The result schema does not change the shared CLI/MCP query projection, text JSON
payload, evidence, page/snapshot behavior, or causal interpretation. Its
description explains when to use the tool, names nearby alternatives, and keeps
the read-only and causality limits explicit.

Research and review: [feature research](../mcp-service-flow-output-research.md)
and [review decision](../mcp-service-flow-output-review.md).
