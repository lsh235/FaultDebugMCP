# v1.3.0-alpha.23: typed source-evidence results

Date: 2026-10-17 (Asia/Seoul). Python package `1.3.0a23`; native project
version remains `1.3.0`. Alpha23 publishes a typed success/error contract for
`get_source_evidence`, which is available in both full and Glama's recommended
focused profile. It distinguishes verified citations from unresolved source
references and payload-level store/bundle errors. Source text remains the
separate `get_function_source` result.

The existing text JSON, filter and verification behavior are unchanged,
including single-citation flat convenience fields. In `structuredContent`, the
MCP SDK may include those optional fields as null when the text response omits
them. A schema-valid structured result is wrapped under `result` because the
tool's result is a success/error union.
