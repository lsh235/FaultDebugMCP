# v1.3.0-alpha.12: integrated report language

Date: 2026-10-17 (Asia/Seoul). Python package `1.3.0a12`; native project remains
`1.3.0`. Baseline: alpha11 commit
`ccc10b17740ae2cd076151b0bf8e0e5823aec39b`.

## Behavior

`faultdebug integrate --fault-report-language en|ko` selects the language of
the JSON, Markdown and HTML report generated by `--fault-report`. The language
option requires `--fault-report`; both report options still require
`--execute-target`. English remains the default. The existing translation and
report builder are reused, so capture validation, source-bundle verification,
target/report status separation and output collision handling retain alpha11
behavior.

See the [research](../integration-report-language-research.md),
[feature review](../integration-report-language-review.md), and
[adoption guide](../existing-project-adoption.md).
