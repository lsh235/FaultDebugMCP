# v1.3.0-alpha.28: typed address-resolution results

Date: 2026-10-17 (Asia/Seoul). Python package `1.3.0a28`; native project
version remains `1.3.0`. Implementation: `da4bf732b8b67d4a427d13532e06a5abaa85b28d`.

This alpha publishes a typed `resolve_addresses` result in both MCP profiles.
Its `items` rows reuse the existing Build-ID-aware resolution contract for
captured addresses, optional symbols/function IDs, static relations and
explicit unresolved reasons. The resolver, local-only lookup rules, input
validation, errors and text JSON remain unchanged. Optional source/debug and
index fields remain permissive.

The alpha28 candidate review rejected a full-only `get_evidence_summary`
schema because it would not affect the repository's documented focused Glama
catalog. A new research/review cycle then selected `resolve_addresses`, which
is present in that focused profile. This scope choice does not imply that the
external Glama configuration currently uses the documented profile.

The full profile remains 27 tools/84 parameters and focused remains 15/44.
Published output schemas increase to 12 full and 11 focused.
