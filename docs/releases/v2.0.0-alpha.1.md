# FaultDebugMCP v2.0.0-alpha.1

Date: 2026-10-17 (Asia/Seoul)

This prerelease starts the v2.0 major line with a deliberate default MCP API
change. `faultdebug mcp --root PATH` and `make_server(PATH)` now expose the
15-tool `focused` catalog instead of the previous 27-tool `full` catalog.
`get_call_relations` is no longer listed or callable in the default profile;
the unchanged 27-tool catalog remains available through
`--tool-profile full` or `make_server(root, tool_profile="full")`.

This is an incompatible public contract change under [Semantic
Versioning](https://semver.org/spec/v2.0.0.html), so it starts a major version.
The Python package is `2.0.0a1`; the native CMake package is `2.0.0`. Native
runtime ABI/SONAME v1, FDAR v1, shared-memory ABI v1, semantic RPC schema v1,
and evidence-store base schema v2 remain unchanged. CMake consumers that pin
package major 1 must update to `find_package(faultdebug 2 CONFIG REQUIRED)`.

## Implementation and migration

- Implementation commit: `a9148294e8bc8d6be06db8ceb23e88022b654a22`.
- Default tool inventory: 15 tools and 41 described parameters.
- Full tool inventory: 27 tools; the existing static call-relations operation
  remains in `full`.
- CLI migration: add `--tool-profile full` to restore the previous catalog.
- Python migration: pass `tool_profile="full"` to `make_server`.
- The documented Glama configuration pins to the implementation commit, but
  the external administrator setting, deployment, scan, and TDQS score remain
  **NOT VERIFIED**. The smaller default is a score-improvement hypothesis,
  not a measured result.

## Verification

GitHub Actions run [38995793503](https://github.com/lsh235/FaultDebugMCP/actions/runs/38995793503)
tested the exact implementation commit above. Python/package tests, the
packaged MCP container profile check, and Clang 18 CMake/runtime smoke all
passed (3/3 jobs). The package produced sdist and wheel metadata for
`2.0.0a1`; the container exposed 15 default tools and retained all 27 in
`full`.

Local verification also passed for Python sdist/wheel creation, compileall,
the incremental GCC/CMake build, and `git diff --check`. An earlier local full
CTest run was 39/40 because Clang 18 is not installed locally; the corresponding
hosted Clang 18 smoke passed on the implementation commit above. A local stdio audit using the pinned MCP SDK was not
available because the local environment has MCP 1.9.4 while this project pins
1.30.0; the hosted Python and container jobs supplied the current-SDK/profile
checks.
