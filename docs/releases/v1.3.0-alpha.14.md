# v1.3.0-alpha.14: caller-selected integrated report destination

Date: 2026-10-17 (Asia/Seoul). Python package `1.3.0a14`; native project
version remains `1.3.0`. This alpha adds `--fault-report-output PATH` to
`faultdebug integrate` for evidence-bound reports produced after an explicitly
requested target capture.

The option requires `--fault-report`. A relative path is resolved from the
caller's working directory; missing parent directories are created. The final
report directory must not already exist or be a symlink, and publication still
uses the report writer's atomic collision check. Without the option, the
existing report-beside-capture behavior remains. The report continues to use
the validated capture and verified source bundle from the same integration
run; target, report, and overall status semantics are unchanged.

The Meson adoption candidate was researched and deferred because the current
wrapper fixture does not yet establish selected-target provenance and the
runtime/source-note lifecycle required by `integrate`. See the
[candidate research](../integration-report-output-research.md),
[feature review](../integration-report-output-review.md), and
[Meson deferral review](../meson-adoption-review.md).
