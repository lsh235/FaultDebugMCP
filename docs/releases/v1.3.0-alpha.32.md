# v1.3.0-alpha.32: focused count-only evidence summary

Date: 2026-10-17 (Asia/Seoul). Python package `1.3.0a32`; native project
version remains `1.3.0`. Implementation: `3e0f13aeb8a6b019216e711881853a93637c1020`.

This alpha adds `get_evidence_summary` to the focused MCP profile. It exposes a
typed output contract for status, artifact and observed counts, static
candidates, and extensible unresolved diagnostics. The tool is a count-only
triage step before detailed RPC or fault-flow views; it does not change
evidence decoding, interpretation, or storage. `complete` means that this
summary emitted no unresolved diagnostic, not that the target application
succeeded or that capture was exhaustive.

The full catalog remains 27 tools / 84 parameters. The focused catalog grows
from 15 / 44 to 16 / 45. Typed output schemas grow to 16 in full and 15 in
focused. `get_unresolved` remains full-only; an earlier candidate review
rejected exposing it in focused because its broad incident output was not a
coherent fit for the score-focused profile.
