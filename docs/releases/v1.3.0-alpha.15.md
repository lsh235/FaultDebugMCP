# v1.3.0-alpha.15: require verified bundles in source-tool schemas

Date: 2026-10-17 (Asia/Seoul). Python package `1.3.0a15`; native project
version remains `1.3.0`. `get_function_source` and `get_call_relations` now
declare their verified `bundle` argument as required and non-null in MCP
`tools/list`, matching the existing handler behavior.

This removes calls that were schema-valid but predictably failed because the
source functions cannot operate without an immutable verified bundle. Capture
inspection tools retain optional bundles. All 26 tool names and read-only
annotations remain unchanged. The change is intended to improve published
parameter semantics and reduce wasted tool calls; it does not claim a numeric
Glama TDQS increase. The current score could not be fetched (public API returned
HTTP 401), so only a Glama re-scan can confirm any score change.

[review](../mcp-required-bundle-review.md), and
[Glama container guidance](../mcp-container.md).
