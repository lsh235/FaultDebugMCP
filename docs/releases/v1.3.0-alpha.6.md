## Behavior

The new read-only `faultdebug debug-verify PACKAGE_DIR` command validates the
package manifest schema, safe relative paths, non-symlink file locations,
runtime/debug SHA-256 values, DWARF section presence, and Build-ID parity with
the manifest. This checks package-internal consistency after it is copied or
deployed. It does not rehash the source binary because that binary is not
included, and the manifest is not signed. Build ID and SHA-256 checks do not
establish publisher identity or source provenance.

No ABI, FDAR, RPC, evidence-store, or MCP tool schema changes are intended.
The check is local, read-only, and makes no network requests.
