# v1.3.0-alpha.25: typed fault-flow output

Date: 2026-10-17 (Asia/Seoul). Python package `1.3.0a25`; native project
version remains `1.3.0`. Implementation: `e277d336800f016f30a714a2b9e3169acbfa41f3`.

Alpha25 publishes a typed `get_fault_flow` output in both full and focused MCP
profiles. The schema documents capture state, thread and event nodes, crash
records, evidence edges, gaps, diagnostics, address-resolution details,
verified source excerpts and the optional verified-bundle marker. Producer-
varying target metadata, snapshot data and resolution extensions remain open.
The report algorithm, text response, bounds, source verification, tool
inventories and evidence files are unchanged. A display-truncated view remains
distinct from capture loss, and no edge is a root-cause verdict.
