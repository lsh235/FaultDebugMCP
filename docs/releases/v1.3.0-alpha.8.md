## Behavior

`faultdebug self-test` checks Linux x86_64 setup prerequisites, compiles a fixed
generated C fixture through the installed `faultdebug-cc` wrapper, captures it
with the selected native runtime, and parses the persisted temporary artifact.
PASS requires a successful target and collector, a complete and stable trace,
at least one event, and no reported thread or RPC drops. Missing setup returns
`NOT RUN` before compilation; a broken capture returns `FAIL`.

The command runs only its generated fixture. It does not execute user source,
validate project-wide instrumentation or source resolution, retain its
temporary artifact, or measure production performance. A successful self-test
is installation-path smoke evidence, not external-project acceptance or stable
release acceptance. See [research and decision](../self-test-research.md).

Quick use after installing the Python package and native runtime:

```sh
FAULTDEBUG_REAL_CC=clang-18 faultdebug self-test
```
