# v1.3.0-alpha.13: bounded integrated report context

Date: 2026-10-17 (Asia/Seoul). Python package `1.3.0a13`; native project
version remains `1.3.0`. Baseline: alpha12 commit
`4fd13eff8d19cf72c1e9fb9d5a38dff773faead9`.

## Behavior

`faultdebug integrate --fault-report-max-events 1..500` selects the newest
pre-crash events shown per thread in the JSON, Markdown and HTML report. The
default remains 80. The existing report records the count omitted from the
display, while the capture itself and its completeness status remain
unchanged. The option requires `--fault-report`; invalid ranges and non-integer
values are rejected before project preparation or execution.

Meson adoption was considered and deferred. The existing Meson fixture covers
compiler-wrapper instrumentation, while `integrate` also guarantees selected
target identity, a source-snapshot note, runtime linkage, and verified capture
bundle. The current Meson path does not yet implement an equivalent lifecycle.
See the [Meson research](../meson-adoption-research.md) and
[review](../meson-adoption-review.md).

See the [event-limit research](../integration-report-event-limit-research.md),
[feature review](../integration-report-event-limit-review.md), and
[adoption guide](../existing-project-adoption.md).
