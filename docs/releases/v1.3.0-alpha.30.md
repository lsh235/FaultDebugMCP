# v1.3.0-alpha.30: typed raw thread traces

Date: 2026-10-17 (Asia/Seoul). Python package `1.3.0a30`; native project
version remains `1.3.0`. Implementation: `4a796fea690df0dc19417da303b40aa61be7f3fb`.

This alpha publishes a typed `get_thread_trace` page and raw thread/event
contracts in both MCP profiles. Native ABI rows expose their generation,
recorded addresses, sequence and retention accounting; unknown producer
extensions remain open. Sparse `.json` captures are returned without
normalization, so native row fields are nullable in structured output and
absent keys remain absent in text JSON. `tid` matching across generations,
event order, pagination, required inputs, errors, evidence and tool inventory
remain unchanged. These raw events are not symbolized calls and do not prove
capture completeness.

Full/focused profiles retain 27/84 and 15/44 tools/parameters. Typed output
schemas increase to 14 full and 13 focused.
